# 116117-suche
Dingens dass mir Chatgpt gebastelt hat zum Text von der 116117 Website in eine csv Tabelle zu konvertieren. 

Anleitung: 
1. outerHTML von #app > div > div > div.main-content-inner-container.no-focus-outline > div > div > div.outer-list-container > div > div.search-results-container kopieren
2. Text extrahieren
3. cd ~/Desktop && mkdir -p ~/Desktop 116117suche && cd ~/Desktop/116117suche && curl -O https://raw.githubusercontent.com/tresitresen/116117-suche/main/116117_parser.py
